Retrofit 到底是什么？
一句话定义： Retrofit 是一个将 HTTP API 转换成 Kotlin/Java 接口的工具。你只需要定
义一个接口，写上注解，Retrofit 就会自动帮你完成网络请求、解析 JSON、切换线程等
脏活累活。
通俗比喻：
• 不用 Retrofit：自己写 HttpURLConnection，手动拼接 URL，手动处理流，手动
解析 JSON...（像自己造车）
• 用 Retrofit：你只需要说“我要去北京”，Retrofit 自动给你买票、开车、导航（像
坐滴滴）
为什么学 Android 必学 Retrofit？
对比 原生方式（HttpURLConnection） Retrofit
代码量 20+行一个请求 3 行一个请求
JSON 解析 手动用 Gson/JSONObject 自动完成
线程切换 自己开子线程、Handler 配合协程自动切
错误处理 手动判断响应码 统一拦截器
URL 拼接 手动拼接字符串 用注解@GET("user/{id}")
结论： 现在的 Android 开发，Retrofit 几乎是网络请求的事实标准。学生不学 Retrofit，
等于没学 Android 网络编程。
Retrofit 的核心三要素（必须理解）
1. 注解（告诉 Retrofit 你要做什么）
kotlin
@GET("posts") // GET 请求，路径是 posts
@POST("user/login") // POST 请求
@Path("id") // 动态替换 URL 中的{id}
@Query("page") // 添加查询参数 ?page=1
@Body // 发送 JSON body
2. 接口定义（你的 API 说明书）
kotlin
interface ApiService {
 @GET("posts")
 suspend fun getPosts(): List<Post>
 
 @GET("posts/{id}")
 suspend fun getPost(@Path("id") id: Int): Post
}
3. Retrofit 实例创建（工厂）
kotlin
val retrofit = Retrofit.Builder()
 .baseUrl("https://jsonplaceholder.typicode.com/") // 基础 URL
 .addConverterFactory(GsonConverterFactory.create()) // JSON 转换器
 .build()
val apiService = retrofit.create(ApiService::class.java) // 生成实现类
完整的课堂示例
假设我们要请求这个 API：https://jsonplaceholder.typicode.com/posts
第 1 步：添加依赖（build.gradle.kts 模块级）
kotlin
dependencies {
 // Retrofit 核心
 implementation("com.squareup.retrofit2:retrofit:2.9.0")
 // Gson 转换器（自动解析 JSON）
 implementation("com.squareup.retrofit2:converter-gson:2.9.0")
 // 协程支持（让 suspend 函数生效）
 implementation("org.jetbrains.kotlinx:kotlinx-coroutines-android:1.7.3")
}
第 2 步：定义数据类（自动映射 JSON）
kotlin
data class Post(
 val userId: Int,
 val id: Int,
 val title: String,
 val body: String
)
JSON 返回 {"userId": 1, "id": 1, "title": "hello", "body": "world"} 会自动
转成 Post 对象。
第 3 步：定义 API 接口
kotlin
interface ApiService {
 @GET("posts")
 suspend fun getPosts(): List<Post> // suspend = 协程专用，不阻塞主线程
 
 @GET("posts/{id}")
 suspend fun getPost(@Path("id") id: Int): Post
}
第 4 步：创建 Retrofit 实例（通常在 Application 或单例类中）
kotlin
object RetrofitClient {
 private const val BASE_URL = "https://jsonplaceholder.typicode.com/"
 
 val apiService: ApiService by lazy {
 Retrofit.Builder()
 .baseUrl(BASE_URL)
 .addConverterFactory(GsonConverterFactory.create())
 .build()
 .create(ApiService::class.java)
 }
}
第 5 步：在 ViewModel 中使用
class MainViewModel : ViewModel() {
 fun loadPosts() {
 viewModelScope.launch {
 try {
 val posts = RetrofitClient.apiService.getPosts()
 // 更新 UI (用 LiveData 或 StateFlow)
 _posts.value = posts
 } catch (e: Exception) {
 // 处理错误（网络断开、超时等）
 _error.value = e.message
 }
 }
 }
}
学生常见问题及解答
Q1：为什么要用 suspend 函数？
A： 网络请求会阻塞线程。用 suspend 可以让 Retrofit 自动切换到后台线程执行，完成后
切回主线程，不会卡界面。
Q2：baseUrl 有什么要求？
A： 必须以/结尾。"https://api.com/" ✅ "https://api.com" ❌
Q3：怎么调试看请求是否成功？
A： 添加日志拦截器：
kotlin
val logging = HttpLoggingInterceptor().apply {
 level = HttpLoggingInterceptor.Level.BODY
}
val client = OkHttpClient.Builder()
 .addInterceptor(logging)
 .build()
Retrofit.Builder()
 .client(client) // 加上这个
 .baseUrl(BASE_URL)
 ...
Q4：没有后端怎么办？
A： 用公共测试 API：
• JSONPlaceholder: https://jsonplaceholder.typicode.com/
• ReqRes: https://reqres.in/
• 自己 Mock：用 MockWebServer（暂不推荐，太复杂）
Q5：POST 请求怎么发 JSON？
A：
kotlin
interface ApiService {
 @POST("posts")
 suspend fun createPost(@Body post: Post): Post
}
// 调用时
val newPost = Post(userId = 1, title = "New", body = "Content")
val created = apiService.createPost(newPost)
